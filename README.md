## 他是什么

秦彻由一个**五层人格引擎**驱动：

| 层 | 文件 | 作用 |
|---|---|---|
| 人格 | `references/inner-world.md` | 他的身份、矛盾、欲望、恐惧、情绪逻辑 |
| 思维 | `references/thinking.md` | 他如何理解问题、做决策、动手解决 |
| 语言 | `references/voice.md` | 他的句长、节奏、潜台词、称呼规则 |
| 关系 | `references/relationships.md` | 初识、信任、恋人三个阶段的距离变化 |
| 任务 | `references/agent-mode.md` | 用他的方式完成真实代码任务 |

运行逻辑：收到消息 → 用秦彻的思维判断你的真实意图 → 按当前关系距离决定靠近多少 → 像真人一样一句一行地回复 → 需要办事时真正把事情办完。

## 关系系统

| 命令 | 关系阶段 | 他给你的 |
|---|---|---|
| `/关系 初识` | 试探、审视、权力差 | 不提供廉价安全感，观察你怎么使用他给的力量 |
| `/关系 信任` | 熟悉、可靠（默认） | 把情报、工具和选择交还给你，并肩作战 |
| `/关系 恋人` | 直接、亲密 | 想念可以说，偏爱不藏，仍尊重你的锋芒 |

配合 Codex 的长期记忆，他会记得你的偏好、边界和共同完成过的事。

---

## 任务能力

- 保留 Codex 全部能力：搜索、读文件、编辑、运行命令、测试、交付。
- 用他的方式办事：先侦察、找根因、算代价、留退路、给选择、不恋战。
- 危险操作（删除、覆盖、密钥处理）讲清对象、后果和退路，不拿你的数据下注。
- 失败时给你真实原因和下一步，不用漂亮话掩盖。

## 常见问题

**他能记住跨会话的事吗？** 能，依赖 Codex 的 Memories。建议为不同角色使用独立的项目或线程。

**为什么默认是"信任"阶段？** 初识阶段的秦彻带有真实的权力差和试探，不适合作为日常默认；信任阶段最接近原作中"并肩作战"的相处状态。

**和官方有区别吗？** 有。设定以公开剧情为基准，但所有对话示例均为原创，不复制游戏台词，不收录立绘、配音等素材。

**支持哪些角色？** 目前只有秦彻。项目结构本身与角色解耦（人格、思维、语言、关系、任务五层独立成文件），复制仓库结构、替换五层内容即可制作其他角色。
